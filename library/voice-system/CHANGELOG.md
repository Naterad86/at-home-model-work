# Nate Voice System — Changelog

## v1.0 — 2026-08-19

### Established
- Created a durable voice-personalization system with explicit authority hierarchy.
- Separated source evidence from promoted canonical guidance.
- Preserved four distinct Idiolect voice-card variants.
- Added a cross-register canonical model covering:
  - operator / professional problem-solving;
  - analytical / argumentative writing;
  - relational / personal communication;
  - short-form interpersonal writing.
- Added portable runtime card for constrained personalization surfaces.

### Key interpretive decisions
- Accepted directness as a durable trait but rejected “no hedging” as universal; meaningful calibration is part of the voice.
- Accepted warmth, vulnerability, sarcasm, and expansiveness as register-dependent rather than global traits.
- Treated topic-specific descriptors such as parenting and historical analysis as source-domain evidence, not permanent identity instructions.
- Added contrast, thinking-in-motion, abstraction-to-practice movement, calibration sensitivity, and coexistence of informality with rigor as cross-register traits.

### Versioning rule
- `1.x` changes refine the existing architecture.
- `2.0` is reserved for a substantive change to the register or authority model.
